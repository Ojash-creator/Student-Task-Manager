# Student Task and Deadline Management System

A Flask + SQLite web app that helps students track assignments, projects and exams by deadline, priority and status.

## Features
Dashboard statistics, add/edit/delete tasks, mark complete/pending, search and filters, overdue and urgent highlighting, persistent SQLite storage.

## Technology Stack
HTML5, CSS3, Python (Flask), SQLite, Git, GitHub, VS Code.

## Installation
```
python -m venv venv
venv\Scripts\activate        # Windows  (Mac/Linux: source venv/bin/activate)
pip install -r requirements.txt
```

## Run
```
python app.py
```
Open http://127.0.0.1:5000
